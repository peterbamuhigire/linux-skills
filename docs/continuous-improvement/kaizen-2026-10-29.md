## Findings, experiments and disposition

All actions are owned by the Linux engine maintainer (Peter Bamuhigire).
Implementation was delegated to explicit Luna/high workers; a separate
Luna/high reviewer inspected the real diff. The daemon interruption ended the
first worker set; root inspected saved state and resumed bounded tasks rather
than claiming those workers remained active.

| Finding / cause | Change and verification | Recovery / disposition |
|---|---|---|
| Predictable `/tmp/sk-cleanup.$$` trusted attacker-controlled path lists | Private random mode-0700 directory, NUL records, failure to initialise aborts; symlink and newline fixtures | Original victim survives; cleanup remains isolated. Closed for tested threat model |
| Predictable `<target>.new` could follow a planted symlink | Unique sibling temp, reject target symlinks/non-files, exact-target rename | Symlink referent unchanged; originals survive metadata failure. Closed for trusted parent directories |
| Metadata errors ignored; replacement could default to 0644 | Fail closed on required stat/chown/chmod; skip redundant ownership changes | Failed-stat test retains content/mode; custom metadata remains open |
| SSH grep used last-match ordering and inferred defaults | Query `sshd -T`; empty/failed output unassessed; password and keyboard-interactive distinguished | No service changes; Match/launch overrides require separate operator checks |
| UFW `inactive` matched substring `active` | Require exact `Status: active` | Active/inactive regression cases pass |
| Failed/stale package query could claim fully updated | Honour query exit status, use cache-only DNF query, remove currency assertion | Failed query explicitly unassessed; vendor matching required |
| Fedora minimal lacks cmp; installer interpreted absence as different content | Require diffutils before installation/update destinations are touched | Missing dependency exits 5; no destination mutation; install/reinstall/uninstall fixtures pass after dependency provision |
| Baseline mismatch not reflected in structured validator summary | Include count failures before calculating summary/baseline match | Negative count fixture exits 1 with accurate `failure_counts` |
| CI omitted Python tests and used movable action tags | Add pytest, immutable existing action-release SHAs, read-only permissions and Fedora job | Static workflow tests; hosted results must be read separately |
