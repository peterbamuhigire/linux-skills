# Recommended Books and Reading Material

## Must Encode Now

| Title | Author/issuer | Gap filled |
| --- | --- | --- |
| UNIX and Linux System Administration Handbook, 5th ed. | Evi Nemeth et al. | Breadth and practical operations judgment. |
| Site Reliability Engineering | Betsy Beyer et al. | Operational reliability, alerting, and incident discipline. |
| Linux Hardening in Hostile Networks | Kyle Rankin | Practical hardening and defensive operations. |
| CIS Benchmarks | Center for Internet Security | Consensus Linux hardening controls and evidence expectations. |
| Red Hat Enterprise Linux Security Hardening Guide | Red Hat | SELinux, audit, crypto, and RHEL-specific hardening. |

## Deepen Later
